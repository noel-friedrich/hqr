Human-readable QR codes

Who says QR codes aren't human readable? Well, everyone! So let's change that by integrating text directly into QR codes, while still making them readable and without removing their magical Error-Correction abilities.

Generate an HQR Code

Enter a given message (e.g. a website url) and generate a QR code that contains the encoded message in a tiny bitmap font. Choose the original Tom-Thumb or a Pixiie font below. Keep your message short; long texts will take long times to optimize.
Importantly, this doesn't just place the text and thus abuses error correction, but it actually modifies the padding data, masking and alignment to design a QR code that only uses minimal Error Correction to show the encoded text. For more fun details on the Maths behind this, see this great blogpost by Ross Cox.

Editing the QR Code
